## Overview

This repo is a single-file GIMP 3.0 Python-Fu script that generates a grid collage from a folder of images. It is written in Python 3 and runs inside GIMP 3.0's Python Console via the GObject Introspection API (`gi.repository.Gimp`). The entry point is `batch_collage_gimp_3.0.py`, pasted into GIMP's Filters > Python Console and executed with `exec(open(...).read())`. The script scans a configured image folder, computes uniform cell dimensions from the average of all input image sizes, then builds a new GIMP image by loading each source file as a named layer positioned at its grid offset. Four constants at the top of the script (`FOLDER`, `COLUMNS`, `OVERLAP`, `NUM_PICS`) control all behavior; no CLI or external dependencies beyond GIMP itself are required.
